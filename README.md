
# EduControl – Sistema de Cursos e Matrículas

## Integrante

* Miguel Ribeiro Fleck , Jonatha

## Domínio

Sistema de Cursos e Matrículas.

## Descrição do Projeto

O EduControl é um sistema desenvolvido para auxiliar instituições de ensino no gerenciamento de cursos, alunos e matrículas.

O objetivo é centralizar as informações em um único ambiente, facilitando o cadastro de cursos, o gerenciamento de alunos, o controle de vagas e o acompanhamento das matrículas realizadas.

Ao longo do semestre, o sistema será desenvolvido utilizando os conceitos de Programação Orientada a Objetos, permitindo a evolução gradual das funcionalidades.

## Funcionalidades Previstas

* Cadastro de alunos;
* Cadastro de professores;
* Cadastro de cursos;
* Realização de matrículas;
* Consulta de cursos disponíveis;
* Controle de vagas;
* Cancelamento de matrículas;
* Consulta das matrículas do aluno;
* Gerenciamento de usuários;
* Emissão de relatórios.

## Tecnologias Previstas

## Objetivo

Desenvolver um sistema que torne mais eficiente o processo de gerenciamento de cursos e matrículas, proporcionando uma organização melhor das informações e facilitando o trabalho da instituição de ensino.
